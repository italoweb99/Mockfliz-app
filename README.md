# Mockflix


Esse projeto é o trabalho trabalho da disciplina de desenvolvimento mobile da Centro Universitário Municipal de Franca (Uni-FACEF) e consiste na criação de um aplicativo capaz de acessar a API TMDB
e exibir informações sobre os Filmes.

## Instalação

Tenha certeza que seu dispositivo tenha suporte a android 14 ou superior.  

Clique no link e faça o
[Download](https://github.com/italoweb99/Mockfliz-app/releases/download/v0.0.1/Mockflix.apk).  

instale o apk no seu dispositivo.

## Uso

### Login

assim que entrar no app, faça o login

![Captura de tela 2025-04-29 232553](https://github.com/user-attachments/assets/7653915f-50ac-4f6b-98da-3f056341a8ae)

### Ou

Clique em registrar-se e faça o registro

![Captura de tela 2025-04-29 232615](https://github.com/user-attachments/assets/547c4b5f-d4e1-4655-b6de-0414caee5459)

### Seleção de Filmes

Ao abrir o site são mostrados uma grande seleção de filmes, divididos em categorias como Em Cartaz, Mais populares, e mais bem avaliados. Ao clicar nos filmes será direcionado para uma página com mais informações dos filmes.

![Screen_recording_20250429_203428-ezgif com-optimize](https://github.com/user-attachments/assets/824c3791-bd10-404f-b0f6-ed7c69e9a2e2)

### Mais informações

Ao clicar no filme será exibido, se disponível, o trailer do filme, genero, ano de lançamento e uma breve descrição sobre o filme
